# 历史工单样本（供 Dify 知识库上传）

## WO-20250601-001 营业厅系统登录超时
- 分类：应用访问
- 现象：多个网点反馈登录页面转圈后超时，约 10:30 开始
- 根因：认证服务 Redis 连接池耗尽
- 处理：扩容 Redis 连接池上限，重启认证 pod，恢复会话服务
- 需采集：影响网点数量、是否全省、网关 5xx 比例、Redis 连接数曲线

## WO-20250601-002 订单服务主机 CPU 告警
- 分类：主机资源
- 现象：CPU 持续 92% 超 20 分钟，订单提交变慢
- 根因：批对账任务与高峰重叠，单进程占满 CPU
- 处理：将批任务延后至 01:00 窗口，限制 cgroup CPU
- 需采集：top 进程列表、是否刚发布、批任务 ID

## WO-20250602-003 MySQL 从库延迟告警
- 分类：数据库
- 现象：Seconds_Behind_Master > 600，读接口偶发超时
- 根因：夜间大表 UPDATE 未分批
- 处理：暂停 ETL，拆分批次执行，延迟降至 30s 内
- 需采集：延迟曲线、正在执行的 SQL、主从 IO 状态

## WO-20250603-004 日志盘磁盘 88%
- 分类：存储
- 现象：/var/log 分区使用率 88%，写入变慢
- 根因：应用 debug 日志未降级，未按策略切割
- 处理：调整 log level 为 INFO，执行 logrotate，清理 30 天前归档
- 需采集：目录占用 Top、最近变更单、是否可扩容
