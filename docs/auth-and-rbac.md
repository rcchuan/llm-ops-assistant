# 用户认证与角色权限

## 角色矩阵

| 能力 | 普通运维人员 | 管理员 |
|---|---:|---:|
| 登录、退出、查看自己 | 是 | 是 |
| 修改自己的密码 | 是 | 是 |
| 查看用户列表和详情 | 否 | 是 |
| 创建普通运维人员 | 否 | 是 |
| 启用、禁用普通用户 | 否 | 是 |
| 重置普通用户密码 | 否 | 是 |
| 创建、禁用或重置管理员 | 否 | 否 |

管理员创建的普通用户和被重置密码的用户均设置 `must_change_password=true`。强制改密期间，受保护业务依赖统一返回 `403` 和错误码 `PASSWORD_CHANGE_REQUIRED`。

## API

| 方法 | 路径 | 权限 | 主要响应 | 主要错误码 |
|---|---|---|---|---|
| POST | `/api/v1/auth/login` | 公开 | Token 与安全用户字段 | 401、403、422 |
| GET | `/api/v1/auth/me` | 已登录 | 当前用户安全字段 | 401、403 |
| POST | `/api/v1/auth/change-password` | 已登录 | 安全结果消息 | 400、401、403 |
| GET | `/api/v1/users` | 管理员 | 分页用户列表 | 401、403 |
| GET | `/api/v1/users/{user_id}` | 管理员 | 用户安全字段 | 401、403、404 |
| POST | `/api/v1/users` | 管理员 | 新建普通用户 | 400、401、403、409、422 |
| PATCH | `/api/v1/users/{user_id}/status` | 管理员 | 更新后的用户 | 401、403、404 |
| POST | `/api/v1/users/{user_id}/reset-password` | 管理员 | 安全结果消息 | 400、401、403、404 |

所有用户响应都排除 `password_hash`。用户名在业务层统一转为小写，数据库用户名列使用大小写不敏感排序规则和唯一索引。

## Access Token

JWT 最低 claims（声明）：`sub`、`username`、`role`、`token_version`、`exp`。后端每次请求都会重新查询用户，确认用户存在且处于启用状态，并比对当前 Token 版本、使用数据库当前角色执行授权。禁用账号、管理员重置密码和用户主动改密会递增版本，使此前签发的 Token 永久失效；重新启用账号不会恢复旧 Token。

阶段 2 不实现注册、Refresh Token、邮箱、验证码、找回密码、MFA、账号锁定或 OAuth/OIDC。
