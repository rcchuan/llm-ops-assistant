## Dify 临时不可用兜底

1. 保留页面真实错误与健康检查状态，不刷新到“看起来成功”。
2. 说明 blocking 调用、来源展示和 Dataset 同步的既有契约。
3. 跳过依赖 Dify 的写入和复问步骤，将该项记录为阻塞；不使用录制结果冒充本次实测。
4. 不自动重试 Dataset 同步；结果不确定时先按唯一标识在 Dify 控制台对账。
